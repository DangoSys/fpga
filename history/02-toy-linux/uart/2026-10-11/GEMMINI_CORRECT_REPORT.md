# Toy 8×8 Gemmini 分块与 WS 偏置修复

2026-10-11；Arty A7-100T，`xc7a100tcsg324-1`。
前一轮真实失败的分块与非零 WS 偏置回归已通过；保留原程序、参考算法、比较及二进制。
CPU、Sv39、FP16/32/64、8×8 阵列、全 DSP PE、RF LUTRAM、共享 FMA 和全部保留指令不变。

## 根因与改动

- 并发 MVIN/MVOUT 共用分组查询，原实现让 storer 覆盖 loader 的查询地址，两者无条件采样同一回复。
  A 应有 1 组却拿到 C 的 4 组，导致重复覆盖输入行并读到矩阵之外。增加请求/响应握手和轮询仲裁，
  保持两级查询地址及回复归属；仅串行化配置查询，DMA 数据搬运仍可并发。
- WS 循环原来固定预装 A，并把 B 当作偏置输入。现在按已接受的 CONFIG 锁存模式：WS 预装 B，
  无偏置循环以 zero_op2 清零部分和输入；OS 路径保持原行为。
- 非零 WS 偏置应从 mesh 的 b 端输入；原实现送到 d 端，偏置被忽略。改为 b=偏置、d=0。
- SubROB 同周期入队和退休分别赋值 rowCount，后赋值覆盖前赋值。改为统一占用计数更新，
  同时发生时保持不变；最后一行退休且新行入队时继续执行，不提前报告主指令完成。

所有改动位于 Chisel 源码覆盖层并重新生成 RTL，原版 336 份 Buckyball 导出源文件未修改。

旧 WS-round 核心对同一分块二进制在 OS 第 1 轮失败、同一偏置程序在第 4 项失败；旧基线原样保留。
中间仅修查询的核心通过 OS 第 1 轮，在 WS 第 2 轮失败；加入模式修复后全部 40 轮通过。
原 SubROB 在流式测试丢行断言失败，修复后通过。未降低预期、跳过失败用例或换测试二进制。
历史使用反向比较条件得出的分块 PASS 仍撤回；本轮结果来自修正后的真实比较。

共享 FMA 源码不变，CPU 浮点回归已重新运行；历史 250,819 次 FMA 单元差分仅作为来源证据，本轮未重跑。

覆盖边界：本轮分块压力程序为 M8/N32/K8、shift=0、无循环偏置；不能推广为任意循环尺寸、
跨 K-tile 累加、循环偏置和尾维度都已验证。原 13 项及 64 项覆盖也不能替代这些扩展验证。
