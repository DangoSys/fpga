# Original board source snapshots

These files were recovered byte for byte from FPGA repository commit
`6e8554193a652992a9be28c8647839807ea92284`. Their SHA256 digests match the
non-document entries of `../BOARD_RESULT.json`.

They keep the October 11 implementation evidence bound to its original inputs
after the maintained board sources add optional Flash boot. That implementation
record and its original reports remain unchanged. New Flash implementation and
physical boot evidence are recorded separately under `../../2026-10-12/flash/`.
